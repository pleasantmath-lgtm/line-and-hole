# Window Path Prototype

현재는 스테이지 1(1-X까지), 스테이지 2(2-X까지), 스테이지 3(3-X까지), 스테이지 4(4-2까지)의 16개 레벨을 가진 웹 프로토타입입니다.

## 개발 단계 진행 구조

- 지금은 개발 편의를 위해 모든 레벨이 처음부터 열려 있습니다.
- 현재 레벨 양쪽의 화살표로 이전/다음 레벨로 이동합니다.
- 각 레벨을 시작하거나 초기화하면 조각들이 랜덤 방향으로 놓입니다.
- 조각 색과 조각 보관함 안의 배치 순서는 시작할 때마다 랜덤으로 정해집니다.
- 색이 규칙으로 쓰이는 2-2부터는 조각 색을 랜덤으로 바꾸지 않고, 조각 보관함 배치 순서만 랜덤으로 섞습니다.
- 1-X까지는 조각 이름/순서/색을 정답 단서로 쓰지 않고, 2-2부터는 색이 실제 규칙으로 쓰일 수 있습니다.
- peg가 있는 퍼즐에서는 조각 구멍 수가 peg 수보다 많을 수 있습니다.
- 앞으로 추가하는 퍼즐은 최소 한 조각 이상 회전이 필요하도록 설계합니다.

## 1-1: 기본 peg

- 4x4 보드를 4칸짜리 조각 4개로 빈틈 없이 채웁니다.
- peg가 있는 칸은 구멍이 있는 조각 칸으로만 덮을 수 있습니다.
- 구멍은 peg보다 하나 더 많아서, peg 위치만 보고 바로 정답을 알 수 없게 했습니다.
- 1번, 2번 조각은 처음 방향 그대로는 정답 위치에 들어가지 않아서 회전이 필요합니다.

## 1-2: 경로 찾기

- 1-1과 다른 조각 세트를 사용합니다.
- 보드는 조각으로 빈틈 없이 채웁니다.
- 최소 한 조각은 회전해야 정답 배치가 됩니다.
- 시작점과 끝점은 보드 밖 왼쪽에 있습니다.
- 선이 없는 칸도 있을 수 있습니다.
- 그려진 선들은 모두 하나의 S-G 경로로 쓰여야 합니다.

## 1-3: peg + 경로

- 5x5 보드를 5개 조각으로 빈틈 없이 채웁니다.
- peg가 있는 칸은 구멍이 있는 조각 칸으로만 덮을 수 있습니다.
- 조각에는 peg에 쓰이지 않는 여분 구멍도 섞여 있습니다.
- 그려진 선들은 모두 하나의 S-G 경로로 쓰여야 합니다.
- peg가 꽂힌 구멍 위로 선이 지나가면, 구멍이 선을 끊어 보이게 가립니다.
- S는 위쪽 중앙, G는 오른쪽 중앙에 놓여 있습니다.
- 최소 한 조각은 회전해야 정답 배치가 됩니다.

## 1-4: peg + 경로 연습

- 1-3과 같은 규칙을 한 번 더 연습하는 5x5 퍼즐입니다.
- peg, 구멍, 경로가 함께 나오고, 정답 경로가 모든 조각을 한 번 이상 지나갑니다.
- 조각에는 peg에 쓰이지 않는 여분 구멍도 섞여 있습니다.
- 5개 조각으로 보드를 빈틈 없이 채웁니다.
- S는 위쪽, G는 아래쪽 중앙에 놓여 있습니다.
- 최소 한 조각은 회전해야 정답 배치가 됩니다.

## 1-X: 튜토리얼 종합

- 6x6 보드를 7개 조각으로 빈틈 없이 채웁니다.
- peg, 여분 구멍, 경로 규칙을 모두 사용합니다.
- 경로는 S에서 시작해 보드 전체를 크게 훑고 G로 이어집니다.
- 스테이지 1을 마무리하는 종합 연습 퍼즐입니다.

## 2-1: 좌회전과 우회전

- 5x5 보드를 6개 조각으로 빈틈 없이 채웁니다.
- 긴 L자 조각과 작은 L자 조각을 포함해, 새 규칙이 조각 모양으로도 보이게 했습니다.
- 구멍에 `L`이 있으면 그 칸에서 길이 왼쪽으로, `R`이 있으면 오른쪽으로 꺾여야 합니다.
- L/R 판정은 S에서 G로 길을 따라가는 방향을 기준으로 합니다.

## 2-2: 색 peg

- 5x5 보드를 6개 조각으로 빈틈 없이 채웁니다.
- 조각은 빨간색, 파란색, 노란색 3종류만 사용합니다.
- 색 peg는 같은 색 조각의 구멍으로만 덮을 수 있습니다.
- L/R 구멍은 보조 제약으로 2개만 사용합니다.
- 색, peg, 경로, L/R 회전 방향을 모두 만족해야 성공합니다.

## 3-X: 자석 종합

- 8x8 보드를 4칸짜리 조각 16개로 빈틈 없이 채웁니다.
- 색 peg, L/R, 자석 극성, 자기력선을 모두 사용합니다.
- 고정 색 조각을 사용하며, 조각 보관함의 배치 순서와 방향은 시작할 때마다 달라집니다.
- 스테이지 3까지 배운 규칙을 모두 만족해야 하는 보스 퍼즐입니다.

## 4-1: 다중 경로

- 5x5 보드를 5칸짜리 조각 5개로 빈틈 없이 채웁니다.
- 하나의 S에서 시작한 길이 한 번 갈라져 두 개의 G에 도착해야 합니다.
- 모든 조각에 경로가 지나가며, 남거나 끊기는 선 없이 모든 선을 사용합니다.
- peg와 여분 구멍을 함께 사용하는 다중 경로 튜토리얼입니다.

## 4-2: 두 개의 출발점

- 6x6 보드를 4칸짜리 조각 9개로 빈틈 없이 채웁니다.
- S1은 G1로, S2는 갈림길을 거쳐 G2와 G3로 이어집니다.
- 두 경로는 한 교차로에서 90도로 만나지만 서로 연결되지 않고 제 방향으로 계속 갑니다.
- 두 경로망은 교차로 밖에서 합쳐질 수 없고, 순환하거나 남는 선도 허용하지 않습니다.
- 모든 조각에 경로가 지나가며, peg를 제거하면 복수 해가 생기도록 설계했습니다.

## 조작

- 오른쪽 아래 `도움말` 버튼: 조작법, 크기 조절, 룰 보기 열기/닫기
- 가운데 레벨 버튼: 해금된 레벨 목록 열기
- 한 번 성공한 레벨은 가운데 레벨 버튼과 레벨 목록에서 초록색 완료 상태로 표시됩니다.
- 도움말 안의 `룰 보기` 버튼: 현재 레벨까지 배운 룰 설명 열기/닫기
- 새 룰이 처음 등장하는 단계에 들어가면 화면 중앙에 룰 안내가 뜨고, 오른쪽 위 `x`로 닫습니다.
- 1-1에서는 peg 설명만 보여주고, 1-2부터 경로 설명, 2-1부터 L/R 회전 설명이 누적됩니다.
- `퍼즐판` 슬라이더: 보드 칸 크기 조절
- `조각` 슬라이더: 조각 보관함 칸 크기 조절
- 조각 드래그: 보드 위에 놓기
- 놓인 조각 드래그: 다시 집어서 다른 곳에 놓기
- 조각 좌클릭: 반시계 방향 회전
- 조각 우클릭: 시계 방향 회전
- 도움말의 회전 키 버튼: 누른 뒤 새 키를 입력해서 회전 키 변경
- 기본 `A`: 잡은 조각 반시계 방향 회전
- 기본 `D`: 잡은 조각 시계 방향 회전
- `R`: 현재 단계 초기화
- `해답 검사`: 현재 단계의 해답 수를 0개, 1개, 2개 이상으로 검사
